## 3. 凭据纪律（全文嵌入，零妥协）

1. **禁令（生成物零凭据字面量）**：本项目的代码、配置、示例、测试、文档中，禁止出现任何真实凭据字面量——包括但不限于：口令赋值、API 密钥赋值、访问令牌赋值、私钥块、内嵌口令的连接串。配置值只允许两种出现形式：**环境变量读取**、**明显占位符**（形如 `<YOUR_API_KEY>` 或 `your-api-key-here`）。
2. **配置文件规则**：真实配置走{{凭据策略}}；本地配置文件（`.env` 类）已列入 `.gitignore`，仓库里只允许提交**空值**的示例文件（键名齐全、值全空或占位符）。
3. **可 grep 自检**：提交/打包前在项目根执行，无命中才算通过（命中行须复核是否为占位符或环境变量读取）：

   ```bash
   grep -rniE "(password|passwd|secret|api[_-]?key|access[_-]?token|private[_-]?key)[\"']?[[:space:]]*[:=][[:space:]]*[\"'][^\"'<>{$]" \
     --include="*.js" --include="*.ts" --include="*.jsx" --include="*.tsx" --include="*.py" \
     --include="*.html" --include="*.css" --include="*.json" --include="*.yaml" --include="*.yml" \
     --include="*.md" --include="*.env*" --include="*.sh" \
     --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=.venv .
   ```

4. **需要真实凭据时**：由用户本人填入{{凭据策略}}；AI 会话不经手、不留存、不索要凭据明文。
