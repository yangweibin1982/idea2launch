# 发布前人工检查单（idea2launch）

> 适用：首次对外发布及后续版本发布。分两节：**质量面阻塞项**（全过才发布）与**已裁定不阻塞项**（2026-10-05 用户拍板，记录在案避免翻案）。
> 边界（C3 红线）：`git push`／建仓／社交发布等一切对外动作＝用户亲手动，智能体与脚本不得代执行。

## 一、质量面（阻塞项，逐条打勾）

| # | 检查项 | 通过标准 | 核对方法 |
|---|---|---|---|
| 1 | 占位残留零命中 | 全仓无「占位／待补／M1 交付后补」类残留（模板文件里的**模板占位符**除外——那是给最终用户项目的，须逐处确属模板语义） | `grep -rn "占位\|待补\|交付后补" --include="*.md" .` 逐条人工确认 |
| 2 | LICENSE 与文件协议头核对 | LICENSE 为 MIT 且年份/署名正确；主要源码文件（`shells/**/*.{js,mjs}`、`test/*.mjs`）协议头/来源声明与 LICENSE 一致，无缺署名、无第三方拷入未声明 | 抽查＋全仓 grep `Copyright\|License` |
| 3 | 凭据密钥零命中 | 全仓无 token/password/api_key/私钥等凭据（`.env.example` 只含键名空值属合法） | `grep -rniE "(password|secret|token|api[_-]?key)\s*[:=]" --exclude-dir=node_modules .` 逐条人工确认；有条件再跑一次安全门脚本 |
| 4 | Mimosa 残余告警知情确认 | 对发布时仍存在的扫描告警逐条知情确认。已知模式级误报：first-run-ask 的 argv→fs 告警（根边界校验已落地，用户已复核）——在发布说明注明即可，不装作清零 | 全局安全门脚本＋mimosa 深扫，残余清单附进发布说明 |
