# 原型交付前评审清单

> 用法：交付前对**最终原型**逐条对照；「必过」全过才可交付。三视口截图逐张看过，**禁抽检**。每条缺陷先问「同样的结构还出现在哪」，修根因不修症状。截图工具不限（浏览器开发者工具的设备模拟即可）。

## A. token 与一致性（必过）

- [ ] 无裸值：颜色/间距/字号/圆角/阴影/时长全部走 token
- [ ] 同类组件家族样式一致（按钮/卡片/输入）
- [ ] 间距语义正确：组内 < 组间
- [ ] z-index 走分层令牌，无随手 9999
- [ ] 图标单体系单 stroke，无 emoji 功能图标

## B. 状态完备（必过）

- [ ] 全部交互元素五态：default/hover/active/focus-visible/disabled
- [ ] 数据面三态：loading（骨架同构）/empty（带行动）/error（带重试），以可见示范区块呈现
- [ ] 提交按钮有 loading＋禁用防双击示范态，错误态不清用户输入
- [ ] 表单错误紧贴字段且含图标（色盲可用）

## C. 可达性（必过）

- [ ] 键盘全可达，焦点顺序＝视觉顺序
- [ ] 对比度达标（正文 4.5:1、图形 3:1）
- [ ] focus-visible 全覆盖，无裸 `outline: none`
- [ ] icon-only 按钮 aria-label、图片 alt、modal 焦点陷阱＋焦点归还

## D. 排版细节（必过）

- [ ] 行高合规（西文正文 ≥1.5、中文 ≥1.7）、字长合规
- [ ] 数字 tabular-nums＋右对齐（表格/金额）
- [ ] 截断策略显式（ellipsis/line-clamp＋tooltip）
- [ ] 中文细节：无斜体强调、中西文间距、全角标点

## E. 响应式与主题（必过）

- [ ] 1440 / 768 / 375 三视口截图逐张看过，无溢出/重叠/挤压
- [ ] 含深色主题时深浅两套**截图验证**（定义了≠完成）
- [ ] 320px 不横向滚动

## F. 反 AI slop（必过）

- [ ] 无默认蓝紫渐变、无原生 alert/confirm、无 lorem ipsum
- [ ] 视觉方向符合开工拍板的方向，未漂移回 AI 默认审美

## G. 动效与性能感知（涉动效则必过）

- [ ] 时长 150–500ms、标准缓动、只动 transform/opacity
- [ ] `prefers-reduced-motion` 降级
- [ ] 图片宽高/aspect-ratio 防 CLS，骨架先于数据

## H. 原型专项（必过，本仓新增）

- [ ] 单文件自包含：断网 `file://` 双击可打开，零外部请求（无框架/字体/图标 CDN、无外链图片）
- [ ] data-pid 逐可编辑区块标注，格式 `data-pid="<page>-<block>-<seq>"`（如 `home-hero-01`），无遗漏无重复
- [ ] 文案为真实业务语言（取自 PRD），空态给下一步行动
- [ ] token 来源可追溯（取自 ui-spec.md §9 预设，或项目品牌推导并复校对比度）

---

**出口判据**：A–H 必过项全过＋三视口截图逐张复检 → 可交付；任何必过项未过＝未完成，不进入交付说明。**禁抽检**。
