# 页面模板库 v1（templates-registry）

> 定位：页面模板＝**已验证的「骨架类型×风格」组合**——骨架类型出自 `page-design.md` 布局库五类，风格出自 `ui-spec.md` §9 三套预设（token＝界面里颜色、字号、间距等数值的统一命名，见 `ui-spec.md` §1）。
> 用途：新页面生成前**先查本库**——有适用模板即复制复用、改文案与业务数据；不适用再按布局库从零渲染。省生成消耗、提多页与跨迭代一致性。
> 本库只存元数据不存 HTML 成品；模板本体＝布局库骨架（`page-design.md`）＋token 预设块（`ui-spec.md` §9）的组合，引用不复制。

## 模板元数据 schema（八字段，逐条必填）

| 字段 | 含义 | 填法 |
|---|---|---|
| 名称 | 模板唯一名 | 小写英文＋连字符＋用途短词，如 `list-tool` |
| 风格标签 | 对应风格方向 | `style-anchors.md` 方向名＋`ui-spec.md` §9 预设号 |
| 布局类型 | 对应主骨架类型 | `page-design.md` 布局库五类之一 |
| 组件清单 | 模板含哪些区块 | 布局库区块名（即 data-pid 的 block 段）＋可选区块标注 |
| 适用条件 | 什么样的页面适合 | 一句可判定条件（对照布局库选型判据收窄） |
| 来源 | 模板从哪来 | `内置预设` 或 `某项目沉淀（项目名＋日期）` |
| 版本 | 沉淀后改过几版 | `v1` 起，内容变更递增 |
| 文案占位化说明 | 复用时必做 | 哪些业务文案必须脱敏替换为占位符/本项目文案 |

## 检索流程（逐页生成前四步）

1. **标签匹配**：按本页预期骨架类型＋已拍板风格，在种子模板表找风格标签与布局类型双匹配项；
2. **读模板**：命中→按其组件清单对照布局库该类骨架，确认区块构成适配本页任务；
3. **复制**：以布局库骨架为底、取已拍板 token 预设块，按模板组件清单裁区块、起 data-pid 编号；
4. **差异改写**：按「文案占位化说明」逐区块替换业务文案与示例数据——禁把上一项目的文案带进本项目（脱敏替换完再交用户）。

无双匹配项→本页不适用模板，从零渲染并按布局库选型判据执行；**禁硬凑**。

## 跨项目导出（指针）

模板跨项目导出/导入（模板市场）属 **M3 规划，本仓暂不实现**；当前如需跨项目复用，手工复制本表对应行并把「来源」改为沉淀项目名即可。

## 整理时机

每轮迭代进入 stage-3 开场时**轻裁决一次**：把模板表逐条摊看，该删（长期无人用）、该并（高度雷同）的大白话逐条问用户定去留；增删改后「版本」递增并在「来源」注明整理日期。
