# EDITOR-SPEC — 原型可视化编辑器行为规格

> 归属：idea2launch 第 3 阶段（设计）· `modules/ui-spec/visual-editor/`。
> 依据：`.squad/idea2launch/spec-ui-design-layer.md`（下称「战役规格」）§6/§7/§8/§10。
> 架构：GrapesJS 0.23.6 内核（`lib/grapes.min.js|css`，离线资产）＋薄自建新手 UI；GrapesJS 默认 panels/blocks/style manager/asset manager 全部不渲染。
> 使用方式：双击 `visual-editor.html`（file:// 协议）即可打开；零外部请求，断网可用。

## 1. 定位与边界

**做什么**：载入单文件 HTML 原型 → 可视化点选修改（规格 §10 M1 动作集）→ 导出修改包回传项目。
**不做什么**（战役规格 §1/§10 非目标）：自由画布拖拽、自由 CSS 编辑、组件库面板、撤销树（仅线性撤销）、编辑器内对话式 NL 修改、多项目并行、云端协作。

## 2. 载入

- 双通道：点击「打开原型文件」选择文件，或把文件拖到打开界面中央的拖放区。
- 只接受 `.html/.htm`；非 HTML 文件给出中文提示并拒绝。
- 载入后：文件入口禁用（防止误触覆盖当前工作），直到点「重置」；「重置」有确认弹窗，确认后回到打开界面。
- 首次载入显示三步引导条：①打开文件 → ②点选修改 → ③导出回传；可点「知道了」收起。
- 载入阶段（解析＋初始渲染）不产生任何事件流记录；画布就绪后开始记录。

## 3. 动作集对照表（验收范围＝战役规格 §10 全集）

| # | 动作 | 触发方式 | 行为 | 事件流记录（action） |
|---|------|----------|------|----------------------|
| 1 | 选中 | 画布内单击元素 | 元素浮出工具条（改字/换图/上移/下移/删除，按元素能力裁剪）；选中高亮由内核绘制 | 不记录（选中非修改） |
| 2 | 改字（弹窗） | 工具条「改字」 | 弹窗内编辑纯文本，确定后写回；改动进撤销栈 | `edit-text`，before=旧文字，after=新文字 |
| 3 | 改字（直接编辑） | 画布内双击文字 | 进入内核行内编辑（RTE），输入即改；RTE 自带工具条已隐藏 | `edit-text`，同上（连续输入按 200ms 窗口去重） |
| 4 | 换图 | 工具条「换图」，或双击图片 | 自建弹窗：本地文件转 dataURL 内嵌（上限 2MB，超限拒绝），或粘贴图片网址；不出现内核 asset manager | `replace-image`，before/after=图片地址（截断 120 字），note 注明「本地图片（已内嵌）」或「图片网址」 |
| 5 | 删除 | 工具条「删除」 | 删除选中元素（含子级）；进撤销栈 | `delete` 一条，before=被删内容摘要；级联子级不重复记录 |
| 6 | 上移/下移 | 工具条「上移」/「下移」 | 在同级兄弟中移动位置；到边界给提示不动 | `move-up`/`move-down`，before/after=移动前后第几位 |
| 7 | token 预设切换 | 顶栏「主题预设」下拉 | 替换画布样式表 `:root` 变量值：跟随原型（默认）/默认基座/清爽工具风/温暖内容风（三套块内置，抄自 ui-spec §9，同名变量整组替换，原型自有变量保留） | `apply-preset`，pid=`__theme__`，note=大白话 |
| 8 | 主题色快捷换 | 顶栏色板（10 个候选，均预校白字对比 ≥4.5:1） | 命中主色别名变量组则替换（hover −12%、active −24% 派生）；一组都没命中时补写标准 `--primary` 三件 | `apply-preset`，pid=`__theme__`，note=「把主题色从…换成…」 |
| 9 | 圆角档位 | 顶栏「圆角」三档 | 覆盖 `--radius-sm/md/lg/xl` 四变量（小 2/4/8/12，中 4/8/12/16，大 6/10/16/20） | `apply-preset`，pid=`__theme__` |
| 10 | 密度档位 | 顶栏「密度」两档 | 覆盖 `--space-1/2/3/4/6/8/12/16` 八变量（宽松=4px 基网格原值，紧凑=整体收紧） | `apply-preset`，pid=`__theme__` |
| 11 | 撤销/重做 | 顶栏按钮（无步可撤时禁用） | 内核 UndoManager 线性撤销/重做；组件级变更可撤，token 级变更不在撤销栈（见 §8 边界） | `nl-note` 一条，pid=`__global__`，note=「用户撤销/重做了一步操作」（撤销引发的组件级联不重复入流） |
| 12 | 三视口切换 | 顶栏「视口」桌面/平板/手机 | 内核 Device Manager，桌面 1440 / 平板 768 / 手机 375，画布宽度随之变化 | 不记录（预览行为非修改） |
| 13 | 导出修改包 | 顶栏「导出修改包」 | 下载 `edited.html` ＋ `edits.json` 两个文件（通道 A） | — |
| 14 | 复制修改说明 | 顶栏「复制修改说明」 | 事件流转大白话清单进剪贴板，弹窗内同时展示可手动复制（通道 B） | — |
| 15 | 新增元素 | （编辑器无「新增」入口） | 仅当通过内核能力产生新组件（如粘贴克隆重）时发生 | `add`；无 pid 或 pid 重复的自动分配 `<page>-new-<seq>` |

**主题色别名变量组**（换色时命中即替换）：基值 `--primary` `--accent` `--brand` `--brand-500` `--color-primary` `--main-color`；hover 档 `--primary-hover` `--accent-hover` `--brand-600`；active 档 `--primary-active` `--accent-active` `--brand-700`。

**工具条裁剪规则**：纯文本元素只给「改字/上移/下移/删除」；含图片的元素多给「换图」（目标取选中范围内第一张图）；根节点与无兄弟节点时移动按钮自动失效（点了给边界提示）。

## 4. token 系统实现口径

1. 原型 token CSS **不进** GrapesJS 解析管道（内核会把含 `var()` 的 shorthand 声明拆丢，Spike V1 实证）；由本壳持有原文，注入画布头部 `<style id="i2l-token-style">` 直通渲染。
2. 载入时解析原型 `:root` 变量表为基线；预设/色板/圆角/密度都是在基线上做**同名变量覆盖**后重组 `:root` 块，原型自有变量（如 `--brand-500`）永不丢失。
3. 导出时 token CSS 原文在前、内核增量规则在后拼回单个 `<style>`，原型保持单文件。

## 5. data-pid 协议落地（战役规格 §6）

- 编辑事件取被操作元素**最近祖先**的 `data-pid`。
- 新增元素（含粘贴克隆出的重复 pid）自动分配 `<page>-new-<seq>`（page 取原型文件名小写化，freeze 时智能体重整编号）。
- 全局 token 操作（预设/色板/圆角/密度）的 pid 占位 `__theme__`；撤销/重做占位 `__global__`——保证 §7 要求的 pid 非空且与元素 pid 永不冲突。

## 6. 事件流 schema

字段定义见战役规格 §7（不在此复制）：`schema_version: 1` ＋ `prototype_file` ＋ `edits[]`（`seq/ts/pid/action/before/after/note`）。本编辑器约束：

- `seq` 从 1 起连续自增，每次载入重置；
- `ts` 为 ISO8601；
- `action` 只取枚举 `edit-text|delete|move-up|move-down|replace-image|apply-preset|add|nl-note`；
- `pid` 非空（元素操作=元素 pid；全局=第 5 节占位）；
- `note` 面向用户/智能体的大白话补充，token 操作必带。

## 7. 回传双通道流程（战役规格 §8，文本版）

```
通道 A（主）
  编辑完成 → 点「导出修改包」→ 浏览器下载 edited.html + edits.json
  → 用户把两个文件拖回项目 3-design/ → 回会话说「原型改好了」
  → 智能体读盘：edited.html 与上一版原型 diff，edits.json 对账（schema 见 §6）

通道 B（辅）
  点「复制修改说明」→ 事件流转大白话清单（如
    「1. 修改文字：从『让团队数据一句话可达』改为『新标题』」）
  → 自动进剪贴板（失败时弹窗内手动复制兜底）
  → 用户粘贴回会话 → 智能体按 NL 修改指令执行

禁本地 http 服务自动回写（零运行时依赖）。
```

## 8. 已知边界（M1 明示不做/已知限制）

1. **token 级变更不进撤销栈**：预设/色板/圆角/密度切换不可 Ctrl+Z 回退（事件流留痕）；组件级（改字/删除/移动/换图）可撤。
2. **撤销/重做会产生 `nl-note` 事件**，但不回滚 token 状态。
3. **导出以当前画布为准**：若用户删除后撤销再导出，文件里元素在、事件流里有 delete 记录——智能体对账以文件为准、事件流为操作历史。
4. 本地图片内嵌上限 2MB（防导出包膨胀）；网址方式不做下载转存。
5. 自由画布、自由 CSS、组件库面板明确不做（M2 评估）；双击图片不出现内核 asset manager。
6. 导出修改包会一次下载两个文件，浏览器首次可能询问「允许下载多个文件」，允许即可。
7. 无「新增元素」入口；粘贴克隆产生的新元素按 `add` 记录并重排 pid，子级元素会各自成条（较冗长，属已知行为）。
8. **多页换风格剧本**：换预设/主题色/圆角/密度只作用于当前载入的这一页，且属 token 级变更不可撤销（本节第 1 条）——多页原型想统一换风格，逐页按此剧本走：①点「重置」回到打开界面 → ②载入下一页 → ③换预设/色板先试看，不满意就重置重载（token 级没有撤销，重载是唯一反悔方式）→ ④满意即点「导出修改包」，把该页改动落成 edited.html＋edits.json → ⑤下一页重复，直至全部页面过完。导出以当前画布为准（本节第 3 条），一页一导，禁攒到最后一起补导。

## 9. 验证方法

`test/verify-editor.mjs`（Playwright 实测，方法沿用 `.squad/idea2launch/spike-v1/verify.mjs`）：file:// 打开编辑器 → 载入 fixture 原型 → 逐项实测选中工具条/改字/删除/上移/换撤销/换预设/换色/圆角/密度/视口/撤销恢复/导出双通道/事件流 schema/离线零请求，逐项输出 PASS/FAIL。运行：

```
node test/verify-editor.mjs
```
