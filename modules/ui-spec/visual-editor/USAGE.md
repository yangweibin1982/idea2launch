# 原型修改工具 · 三步使用卡（给完全没用过的你）

> 这是一个不需要安装任何软件的小工具：双击就能打开，断网也能用。
> 它的用处：让你亲眼看到应用的样子，并亲手把「不对的地方」改到满意为止。

## 三步上手

### 第 1 步：打开工具
在文件夹里找到 **`visual-editor.html`**，双击它——它会在你的浏览器里打开。
打开后你会看到三步引导提示，照着做就行。

### 第 2 步：载入原型，开始修改
把智能体给你的**原型文件**（一个 `.html` 文件，比如 `home.html`）**拖进页面**，或点「打开文件」选中它。

载入后你可以这样改：
| 你想做的事 | 怎么做 |
|---|---|
| 改文字 | **单击**选中它 → 点工具条上的「改字」；或者直接**双击**文字输入 |
| 删掉一块 | 单击选中 → 点「删除」 |
| 挪位置 | 单击选中 → 点「上移」或「下移」 |
| 换图片 | 双击图片 → 选一张本地图片，或粘贴图片网址 |
| 换配色风格 | 顶部「主题预设」下拉里挑一个；或用色板直接换主色 |
| 调圆角/疏密 | 顶部对应档位按钮 |
| 改错了 | 点「撤销」按钮，能一步步退回去 |

### 第 3 步：导出，交还给智能体
改满意后：
1. 点 **「导出修改包」**——浏览器会下载两个文件：`edited.html` 和 `edits.json`；
2. 把这两个文件**拖回**你的项目文件夹里的 **`3-design`** 文件夹；
3. 回到和智能体的对话里，说一句：**「原型改好了」**。

智能体会读取你改过的原型和修改记录，跟你确认后就定稿进入下一阶段。

> 小窍门：也可以点「复制修改说明」，把你的修改清单粘贴到对话里，用文字告诉智能体你还想再改什么。

## 常见问题

**双击打不开 / 打开是白页？**
确认双击的是 `visual-editor.html` 而不是别的文件；如果浏览器显示「阻止了此文件」，点「保留」即可——它是本地文件，不联网。

**改错了想反悔？**
点「撤销」逐步退回；「重做」可以恢复你刚撤销的操作。

**哪里看我现在改到了哪一步？**
每次修改都会记进「修改记录」（导出的 `edits.json` 里能看到完整清单，第几步、改了什么、从什么改成什么）。

**文件放哪、从哪找？**
下载的两个文件通常在浏览器的「下载」文件夹里，把它们一起拖到项目的 `3-design` 文件夹（没有就新建一个）。

**改完要对智能体说什么？**
「原型改好了」——剩下的交给它。如果你想继续改但想让它动手，就把「复制修改说明」的内容粘贴给它，并用大白话补充你的要求。

## 已知边界（现在版本不做的事）

- 配色/圆角/密度这类「整体风格」的调整不在撤销范围内（改文字、删、挪位置可以撤销）；
- 图片用本地文件替换时单张不超过 2MB（会自动内嵌进原型，方便整个文件拷走）；
- 暂不支持从空白新画一个区块——告诉智能体你想要什么新东西，它会更新原型后你再改。

（工具能力详情见同目录 `EDITOR-SPEC.md`。）
