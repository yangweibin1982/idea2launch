# 安装 idea2launch（ZCode 插件壳）

> 本壳＝`shells/zcode/` 目录（插件根）：`.zcode-plugin/plugin.json` 清单＋`skills/idea2launch/` 薄入口技能＋`hooks/` L3 意图提示钩子。
> **壳薄核厚**：技能是薄入口，全部工序逻辑在仓库的 `core/` 目录——安装时必须让 core 可达（两种安装法的差别就在这一步怎么达成）。

## 前置条件

- ZCode 桌面版/CLI（支持本地插件市场，即「添加插件市场」功能）；
- **Node.js ≥ 18** 且 `node` 在 PATH（L3 钩子以 `node` 运行；不装 Node 技能仍可用，仅无 L3 提示）；
- 本仓库本体（`git clone <仓库地址>` 或下载解压），下文以 `<repo>` 指其根目录。

## 方式① 仓库即插件（推荐：更新只需 git pull）

插件根就是本仓的 `shells/zcode/` 目录（自带 `marketplace.json` 本地市场清单，来源 `.` 指向自身）：

1. 打开 ZCode → **插件市场 → 添加 → 添加插件市场**，粘贴/选择目录：`<repo>/shells/zcode`；
2. 进入该市场（名为 **idea2launch-local**）→ **idea2launch → 安装**；
3. 安装完成后**重开会话**（技能与钩子在会话启动时装载）。

> 兼容性备注：个别 ZCode 版本不接受市场条目的 `source: "."`（指向市场根自身）。若添加市场时报错，改用方式②；或把 `shells/zcode` 整个目录复制一份并重命名为 `idea2launch`，对该目录执行同样的添加/安装步骤（目录名与插件名一致最稳）。
> 方式①是本地目录引用安装，技能能按相对路径找到 `<repo>/core/`；若你的 ZCode 版本把插件**复制**进缓存导致 core 探测失败（症状：启动技能后提示「core 缺失」），改用方式②。

## 方式② 复制补全（把 core 复制进技能，安装位置无关）

任选一个空目录作为插件根（下文 `<plugin>`），把壳与核心合成一个自包含插件：

1. 复制壳：把 `<repo>/shells/zcode/` 下的**全部内容**（含 `.zcode-plugin/` 隐藏目录）复制进 `<plugin>/`；
2. 复制核心：把 `<repo>/core/` 整个目录复制为 `<plugin>/skills/idea2launch/core/`（技能薄入口会优先探测这个位置）；
3. 在 ZCode 中把 `<plugin>` 目录添加为插件市场并安装 idea2launch，重开会话。

> 方式②是自包含的——插件被复制进缓存也不影响 core 探测；代价是 core 更新后需重做第 2 步。

## 安装后验证（三步，逐条可照做）

1. **插件列表可见**：ZCode → 设置 → 插件管理 → 列表出现 **idea2launch 0.1.0**，详情页可见技能 `idea2launch` 与钩子 `UserPromptSubmit`（`l3-intent-hint.js`）条目且状态可运行；
2. **技能加载**：在一个空目录开新会话，输入「**启动 idea2launch**」→ 智能体应按九阶段向导开场（能力探测→注入询问→建档选档），而不是当普通聊天闲聊；若提示 core 缺失，按方式②第 2 步补复制；
3. **L3 钩子生效**：在**没有** `idea2launch/` 目录的工作区开新会话，输入「帮我做一个记录喂猫时间的应用」→ 出现 ≤3 行的 `[idea2launch]` 提示（建议九阶段向导、说「启动 idea2launch」开始）且**不自动开工**；再输入一句含「idea2launch」的话 → 不重复提示（白名单豁免）。普通问候（「你好」）→ 无提示。

## 卸载

1. ZCode → 设置 → 插件管理 → idea2launch → **卸载**（或先禁用）；
2. 清理注入残留：若首次运行询问时选过 **on**，检查宿主全局规则文件（如 `~/.zcode/AGENTS.md` 或工作区 `AGENTS.md`）中 idea2launch 注入段并手工删除——本壳选 off/ask 时从不写宿主全局文件；
3. 各用户项目里的 `idea2launch/` 目录是项目进度档案（state.json 等），卸载插件不会删除它；确认不再需要时手工删除即可。

## 常见问题

| 症状 | 原因与处置 |
|---|---|
| 启动技能后提示「core 缺失」 | 插件被复制安装、相对路径断了 → 改用方式②（复制 core 进技能目录） |
| 无 L3 提示 | `node` 不在 PATH，或插件被禁用 → 装 Node.js/检查插件开关；用「设置 → 插件管理」详情页确认钩子可运行 |
| 添加市场报 source 错误 | 版本不接受 `source: "."` → 见方式①兼容性备注 |
| 钩子从不静默/误报频繁 | 提示词设计为零成本误触发（不命中即静默、≤3 行、白名单豁免）；若仍困扰，可在插件管理中单独禁用钩子，技能与闸门流程不受影响 |
